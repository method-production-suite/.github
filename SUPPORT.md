# Getting help

- **Something is broken?** Open a bug report in the app's repository. Say which version and
  operating system, and never attach a real budget, schedule or script: an invented one
  that shows the problem is enough.
- **An idea or a missing feature?** Open a feature request in the app's repository. Tell us
  the production task you are trying to do; that helps more than a description of a
  button.
- **A question about how to do something?** Start with the app's README and its `docs/`
  folder. If the answer is not there, open an issue: a missing answer is a gap in the docs.
- **A security problem?** Report it privately, as [SECURITY.md](SECURITY.md) describes.

The apps are free, and there is no paid support or guaranteed response time. They are
tools, not legal, payroll or accounting advice: check figures that
matter, such as union rates or fringes, against their source.
