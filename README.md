# .github

Organisation profile and default community health files for the
[Method Production Suite](https://github.com/method-production-suite).

- `profile/README.md` is the page shown on the organisation's GitHub home.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` and the templates in
  `.github/` apply to every repository in the organisation that does not have its own copy.
  A repository with its own `.github/ISSUE_TEMPLATE/` folder uses only its own templates.
